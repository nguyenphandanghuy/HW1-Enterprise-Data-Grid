
# HW1 — Production Enterprise Data-Grid

An accessible enterprise-style data grid built with HTML, CSS, and JavaScript.

## Objectives

- Build a responsive data table.
- Implement sorting, filtering, and pagination.
- Support keyboard navigation and accessible labels.
- Work toward WCAG 2.2 AA accessibility requirements.

## Technology

- HTML5
- CSS3
- JavaScript
- Vite

## Run locally

```bash
npm install
npm run dev
```
